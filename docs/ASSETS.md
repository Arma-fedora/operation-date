# Контент и ассеты

Всё, что видит гостья, настраивается в `src/config/`. В комплекте нет чужих фотографий и мемов: вместо них — оригинальные SVG-плейсхолдеры. Это сделано специально, чтобы приложение не выглядело как демо с картинками из интернета и чтобы вы сами решили, что показывать.

## 1. Тексты

| Файл | Что внутри |
|---|---|
| `src/config/app.config.ts` | Название, номер дела, имя героини, версия, список экранов и глав |
| `src/config/characters.config.ts` | Допрос Пломбира, реплики, выборы, секреты, quiz, советы и секрет Михалыча, портрет |
| `src/config/puzzles.config.ts` | Четыре пазла: тексты, правила, подсказки, ошибки, названия улик |
| `src/config/final.config.ts` | Письмо, три варианта ответа, результаты, подписи, тексты про приватность |
| `src/config/trials.config.ts` | Испытания, реплики голубя, колесо досуга |
| `src/config/date.config.ts` | Точки, сценарии, координаты, дисклеймер |
| `src/config/gallery.config.ts` | Карточки архива, условия открытия, подписи, пути к файлам |
| `src/config/music.config.ts` | Треки, привязка к экранам, громкость, файлы или встроенный ambient |

После правок: `npm run typecheck && npm test && npm run build`.

## 2. Фотографии и мемы

Положите файлы в:

```text
public/assets/custom/photos/
public/assets/custom/memes/
public/assets/custom/characters/mikhaylych/
```

Файл из `public/` доступен от корня сайта. Например:

```text
public/assets/custom/photos/first-walk.webp
→ /assets/custom/photos/first-walk.webp
```

В `src/config/gallery.config.ts` добавьте `src` к нужной карточке:

```ts
{
  id: 'first-walk',
  title: 'Та самая прогулка',
  src: '/assets/custom/photos/first-walk.webp',
  alt: 'Мы на набережной, вечер, ветер',
  caption: 'Фото, которое не вошло в дело, но осталось в архиве.',
  kind: 'photo',
  unlock: { type: 'always' },
  order: 9,
  aspect: 'landscape',
  note: 'Личный слот.',
}
```

Если `src` нет или файл не загрузился, карточка автоматически показывает дизайнерский плейсхолдер. Ошибка загрузки не ломает архив.

Рекомендации:

- WebP или AVIF, длинная сторона 1200–1600 px, вес до 300–500 КБ.
- Для портретных карточек — `aspect: 'portrait'`, для квадратных мемов — `'square'`.
- `alt` пишите по-человечески: это важно для доступности.
- Не добавляйте фото людей без их согласия. Если на фото есть третьи лица, лучше выбрать другой кадр.

## 3. Портрет Михалыча

По умолчанию используется встроенный SVG. Чтобы заменить его своим изображением:

1. Положите файл в `public/assets/custom/characters/mikhaylych/`.
2. Откройте `src/config/characters.config.ts`.
3. Заполните:

```ts
export const CHARACTER_ASSETS = {
  mikhaylychPortrait: {
    src: '/assets/custom/characters/mikhaylych/portrait.webp',
    alt: 'Михалыч на закрытом канале',
  },
} as const
```

Если файл не загрузится, компонент вернётся к SVG. Портрет используется в чате канала 1996.

## 4. Музыка

По умолчанию все треки — встроенный Web Audio ambient: гул, помехи, синт. Это не «тишина-заглушка», а полноценный звук, который не требует файлов и не тянет авторские права.

Свои треки:

1. Положите MP3/OGG/M4A в `public/assets/custom/music/`.
2. В `src/config/music.config.ts` добавьте `src` к треку:

```ts
{
  id: 'night-moscow',
  title: 'Ночная Москва',
  artist: 'Ваш исполнитель',
  src: '/assets/custom/music/night.mp3',
  screens: ['planner', 'archive'],
  volume: 0.3,
  loop: true,
  fallback: 'generated:night',
  mood: 'прохладный синт, огни за окном',
}
```

Если файл не удалось запустить, движок использует `fallback`. Значения: `generated:hum`, `generated:night`, `generated:chase`, `generated:seal`, `generated:radio`, `silence`.

Браузеры не разрешают автозапуск звука. Музыка включается после первого нажатия; громкость и выбор трека запоминаются.

## 5. Карта и реальные места

По умолчанию в `src/config/date.config.ts` шесть демо-точек в Москве. Они помечены `isDemo: true`, и планировщик честно показывает «есть демо-точки».

Чтобы добавить реальное место:

```ts
{
  id: 'real-cafe',
  title: 'Название',
  description: 'Почему здесь хорошо.',
  address: 'Улица, дом',
  coords: [55.7601, 37.6184], // [широта, долгота]
  isDemo: false,
  tags: ['кафе', 'разговор'],
  duration: '45–60 мин',
}
```

Затем:

- добавьте ID в нужный сценарий `stops`;
- при необходимости поменяйте `mapCenter` и `zoom`;
- обновите `disclaimer`, если он больше не про демо.

Требования:

- минимум две точки с координатами, иначе карта покажет схему;
- координаты именно `[lat, lng]`, не наоборот;
- сценарии ссылаются на существующие `id`;
- маршрут — схема, а не навигация; расстояние считается по прямой, не по дорогам.

Тайлы — OpenStreetMap. Для публичного трафика с большим числом пользователей подключите свой tile-провайдер или соблюдайте политику OSM.

## 6. Плейсхолдеры

Компонент `src/components/ui/Placeholder.tsx` генерирует уникальную абстрактную карточку по `id`: цвет, линии, номер. Он используется в галерее и не требует картинок. Если хочется другой стиль — меняйте палитры и разметку в одном месте.

## 7. Что не нужно менять

- `src/services/telegram/telegram.ts` — обёртка официального SDK.
- `src/services/audio/AudioEngine.ts` — синтез и проигрывание.
- `supabase/migrations/` — схема. Если меняете структуру, добавляйте новую миграцию, а не редактируйте применённую.
- `supabase/functions/_shared/telegram.ts` — проверка подписи. Ошибка здесь открывает доступ посторонним.

## 8. Чек-лист перед отправкой

- [ ] Все демо-точки заменены или явно оставлены с пометкой.
- [ ] В галерее нет битых файлов; плейсхолдеры выглядят уместно.
- [ ] Проверены тексты на телефоне: длинные абзацы не обрезаются.
- [ ] Финальное письмо и три ответа прочитаны вслух — нет давления и двусмысленных обещаний.
- [ ] Музыка не перекрывает голосовые сообщения и не стартует слишком громко.
- [ ] На фото нет людей без согласия.
- [ ] Сборка `npm run build` проходит, размер основного чанка не превышает разумные пределы.
